Open Cohort

What each tab is for

You do not need every control. Use the main steps below; open the details when you need to inspect a method, check a record or change the setup.

InquiryCorpusEvidenceFindingsGraph

Inquiry starts agent work. Corpus searches source texts. Evidence runs comparisons. Findings lists proposals. Graph shows their sources and relationships.

Inquiry

Give agents a research question and inspect what they produce.

Start here

  1. Choose an example, write a question or select a saved question.
  2. Edit Research instructions to specify the approach and evidence you want.
  3. Click Record question, then Inquire.

Recording saves the question. Inquire starts paid model calls. Opening the tab or choosing an example starts no run.

Question versus instructions

Question: “Where else does this wording occur, and what explains the parallels?”

Instructions: “Find matching passages, compare their contexts and cite the sources. Consider quotation and recurring expressions.”

The instructions guide the agents. They are not an automatically enforced test of whether the question has been answered.

Optional controls
ControlUse it when…
Agent roles and settingsYou want to inspect who will do the work. Workers retrieve and propose; reviewers check claims after the workers finish.
Customize the rosterYou need specific worker tasks or models. The automatic setup is sufficient to start.
Agent ID / ModelYou need identifiable authors and different model families. An agent cannot review its own claim.
Corpus scope / MethodYou want to give an agent a narrower task or approach. These fields are included in its instructions; they do not impose a separate corpus-access filter.
Add agent / reviewerYou need another task or a separate review. More agents do not automatically mean stronger evidence.
Saved questionsYou want to investigate an existing question again. Selecting it does not restart its old run.
Hide a questionYou want to remove it and its exclusively associated records from the graph view. This is a display preference; the records remain saved.
Stop after this turnYou want the active run to stop. An in-flight request can still finish.
What the outputs mean

Current run: execution state, elapsed time, model calls, tool activity and costs. A finished run may contain proposals, refusals or no useful finding.

Refusal: the graph blocked an attempted operation. Open the reason; a refusal is not the same as finding no corpus match.

Previous runs: saved execution summaries. Findings and Graph hold the resulting research records.

Runs continue on the server when you leave the tab. Records save automatically; the server must stay running. Spending limits depend on the server configuration. Turn limits and the stop control still apply.

Getting started: review the question and instructions. Keep model settings and old runs collapsed. Reopen saved findings without rerunning the agents.

Corpus

Find an exact phrase and read its context.

Start here

  1. Type a phrase or click a suggested search.
  2. Open a matching source record.
  3. Click Investigate this passage to prepare a question about that result.

Search and reading are local, read-only operations. Investigate opens an editable Inquiry draft containing the selected source reference. It does not record a citation or start agents.

Controls and outputs
ItemMeaning
Search fieldExact substring search, automatically run after typing pauses. It does not interpret a research question or find semantic paraphrases.
Suggested searchesReady-to-use phrases. Click one to search immediately.
Result countMatching source records returned. The UI calls these “witnesses”; this is not necessarily a count of distinct works or phrase occurrences.
Truncation noticeMore results may exist. The displayed list follows corpus order, not relevance ranking.
Source title / referenceOpens the local text. The reference identifies the record agents should fetch.
Markup toggleHides TEI markup for reading. Displayed character positions then differ from source positions.
Partial text noticeThe displayed content is an excerpt of the fetched record.
CBETA linkOpens the published text externally. Verification uses the local source, which may differ from that edition.

Getting started: use the suggested T0603 phrase, open one result and read its context. Use markup and external links when you need to check the source.

Evidence

Compare short-string counts and test how the result changes when material is excluded.

Start here

  1. Choose T0603 or T0453 using a suggested input.
  2. Read the two leading groups and the score difference.
  3. For the commentary example, enter T1694 in exclusions and click Repeat comparison.

These calculations make no model calls and write no graph records. Excluding a text changes this calculation; it does not delete a source.

What the main result means
OutputMeaning
Leading groupsThe groups whose short-string profiles most resemble the target under this setup. Some groups contain mixed material rather than one translator’s work.
Score differenceThe gap between the two leading comparison scores. It is not a probability of translator identity and should not be compared across different target texts.
No evidence / low evidenceThe selected string set found no usable matches or too few distinct strings for a stronger display. This is a limitation of this comparison.
Matching occurrences / distinct stringsOccurrences count repetitions. Distinct strings count different matching strings. Overlapping strings are not independent evidence.
Excluded unitsMaterial removed from the profiles before scoring. Profiled chapters of the target’s own work are excluded automatically.

Similarities can come from quotation, genre or shared textual history. The tab does not assign a translator.

Optional controls
ControlUse it when…
Text pickerYou want a target beyond the examples. Search by title, identifier or translator name.
Vocabulary and methodYou want to change the strings being counted. Curated strings, common label-free strings and their combination are different experiments. Keep the string set fixed when comparing the effect of exclusions.
Additional exclusionsYou suspect related material is driving the result. Use exact corpus-unit IDs. Chaptered works need each chapter ID; a whole-work ID does not expand automatically.
Restore these textsYou want to remove the additional exclusions and compare the baseline again.
Highlighting groupsYou want a fixed colour comparison between two groups. This changes highlighting, not the overall ranking. Empty means automatic selection, which can change when the setup changes.
Text overview stripYou want to jump to a section of the target. Each cell represents a block of characters.
Corpus exclusions and countsYou need to audit which material entered the experiment.
Detailed tables and colours

Teal and rust: strings favouring the two named highlighting groups. Stronger colour means greater weight under the calculation, not greater historical certainty.

All groups: rankings and remaining profile material. A thin profile contains little comparison material.

String counts and weights: which strings drive the colour comparison. Counts are raw occurrences; rates use string hits as their denominator, not characters. Weights are scores, not confidence estimates.

The corpus’s group order is not a newly inferred date for the target.

Getting started: use the text selector, result and exclusion box. Keep vocabulary, highlighting controls and detailed tables closed unless a question calls for them.

Findings

Read the proposals and inspect their evidence.

Start here

  1. Open one hypothesis.
  2. Read its statement, supporting passages and alternatives.
  3. Follow a citation into Graph to inspect the record or make a decision.

Opening Findings reads saved records. It does not generate, approve or rank proposals by confidence.

What the outputs mean
OutputMeaning
HypothesesClaims and conjectures, newest first. “Hypothesis” is the heading for either kind, not a container made of claims.
StatusProposed, attested, accepted or rejected. Appearing in Findings does not mean accepted.
AssuranceThe kind of checking recorded. A span check establishes quotation location, not the truth of an interpretation.
Supporting passages / witnessesRecorded supporting material. Several passages can come from one source. Related sources may repeat the same evidence.
No supportNo supporting passage is attached. Treat that as a gap to inspect.
Explanation and alternativesThe proposal’s recorded argument, other possible explanations and limitations. These are authored statements, not automatically verified conclusions.
Prospective testA query with an expected result recorded in advance. A query without a result has not yet been tested; this is not necessarily a corpus holdout experiment.
VerificationsLatest recorded checks by method, with mechanical results and reviewer comments distinguished.
Optional sections

Researcher decisions: approved records and rejections with reasons.

Record integrity: checks hashes and compares database reconstruction with the event log. Useful for auditing storage, not for deciding historical questions.

Getting started: open one proposal and one citation. Leave integrity checks and the full decision lists closed.

Graph

See which records support a proposal and which question it addresses.

Open the illustrated node-and-link guide

Start here

  1. Select a question or hypothesis.
  2. Follow its links to supporting passages and source texts.
  3. Inspect the selected record’s checks and status.

Graph reads the saved investigation. It refreshes on entry and while visible. Selecting or moving a node changes no research record.

Shapes and links

Star: research question. Diamond: claim or conjecture. Ellipse: source text. Rectangle: passage. Dot: query. Square: audit record.

Attests, blue: a passage supports a proposal. Addresses, magenta: a proposal responds to a question. Neither link proves that the proposal is correct.

Parallel / descent: related source records; their support is discounted as independent evidence. Tests: a query tests a conjecture.

The legend can show possible statuses that have not occurred in this session. Some imported experiment records use assessment colours; colour alone does not establish researcher acceptance.

Inspector controls and outputs
ItemMeaning
Source contextReads the passage around the recorded quotation.
PayloadThe stored fields for this record. Useful for detailed inspection; usually unnecessary on stage.
Span verificationWhether the latest exact-span check located the quotation. Repeated attempts remain in expandable history.
Incoming / outgoing linksRelationships pointing to or from this record. Click a linked record to inspect it.
AuthorshipWho created or checked the record and who made decisions about it.
AttestRequests promotion after the type-specific prerequisites and reviewer rules are checked. This is not researcher acceptance.
AcceptRecords researcher approval of this record. It must first be attested. Accepting a passage does not accept connected claims.
Reject / reopenRecords rejection or reopens a rejected record, with a reason. History is preserved.
Retract / restore edgeChanges whether a relationship is active. This can change independence assessments; it is an advanced research decision.
Optional graph controls

Refused writes: blocked operations and their reasons. Open this when discussing a specific refusal.

Counts: numbers of stored record types, including audit records. More records do not mean more independent evidence.

Settings: theme and audit-node visibility. Repeated passage span checks stay grouped in the inspector even with audit nodes enabled.

Drag and zoom: arrange the display. These positions do not encode a scholarly ranking.

Getting started: follow one evidence chain. Expand the link explanation if needed. Accept a record only after reviewing it.

This guide describes the current interface. It explains controls, not guarantees of research accuracy. The source corpus, saved graph and Evidence calculations remain separate.
